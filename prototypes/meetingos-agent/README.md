\# MeetingOS Agent Prototype



Experimental prototype for an agentic search layer planned for MeetingOS.



\## Current capabilities



\- Groq-based tool calling

\- Meeting search

\- Meeting retrieval

\- Action-item retrieval

\- Multi-step tool execution

\- Bounded agent loop

\- Basic error handling

\- Basic run metrics



\## Current status



Early prototype. Uses mock meeting data and is not yet connected to the production MeetingOS database.



\## Planned integration



The next step is connecting the tools to the existing MeetingOS database and evaluating retrieval, tool selection, factuality, and failure handling on real meeting records.
